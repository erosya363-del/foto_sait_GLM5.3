## 1. Что это за проект

Мобильный сайт-каталог мебели Askona (русский язык), тестируется владельцем
на реальном iPhone (Safari + PWA-ярлык). Разделы: **Каталог** (фото, дриллдаун
категории→модели→варианты→товар, ткани, поиск), **Остатки** (склады Обухово/
Владимир), **Загрузка фото**, **Админ** (товары, ткани, фотобанк, справочники).
Нижняя навигация — плавающая «пилюля» Liquid Glass с линзой, бегущей за пальцем.

- Стек: **Next.js 16 (App Router) + Bun + Prisma/SQLite + zustand (persist) + framer-motion + Tailwind 4 + sharp**
- Вью = компонентные состояния zustand, НЕ роуты (прямые URL типа /stock дают 404 — это норма)
- БД: `db/custom.db` (SQLite, коммитится в git), фото каталога: `public/catalog/`, загрузки: `public/uploads/` (runtime, в git не храним)

## 3. Ключевые механики — КАК сделано

### 3.1 Пилюля (нижняя навигация)
- DOM: `nav.pill-nav` (fixed, bottom `max(10px, env(safe-area-inset-bottom))`, z-40, pointer-events:none) → `.pill-shell` (max-w 440, h 64px, radius 999px, `var(--glass)` + `blur 28px saturate 1.7`, **touch-action:none**) → 4×`.pill-item` + линза `.nav-lens` (`<motion.span layoutId="nav-lens">`, spring 480/36).
- **Drag-to-select:** на `.pill-shell` pointerdown/move/up/cancel + `setPointerCapture`; пункт под пальцем вычисляется по rect'ам (допуск ±12px); линза и подсветка `.is-drag` едут за пальцем ДО отпускания; на каждом переходе — тихий `playStep()`; на pointerup — активация пункта под пальцем + `suppressClickRef` 500мс (гасит синтетический click).
- **Растворение при скролле:** класс `.pill-dim` на nav (фон 0.38, рамки/тени нет, неактивные пункты opacity .38) — активный пункт остаётся 0.8; касание панели → `.pill-active` (стекло 0.9) до тапа мимо.
- **goCatalog** (`src/components/portal.tsx`): уже в каталоге → `resetCatalog()` + `playTick()` + `haptic(12)` + пульс `.nav-pulse`; переход из другого раздела → `setView("catalog")` + `playTick()` + `haptic(10)` (хотфикс v1.6.1 — звук был только на повторном тапе).
- Клавиатура iOS: `.kb-open .pill-nav` → translateY(170%) (прячется при вводе).

### 3.2 Звук и вибрация (`src/lib/tick.ts`)
- Web Audio: triangle 1750→950 Hz, «tap» peak 0.11/70мс, «step» 0.05/45мс (тише для драга). AudioContext ленивый, создаётся в жесте тапа.
- `haptic(ms)` → `navigator.vibrate` на каждом тике — Android вибрирует. **iPhone: Apple физически не даёт vibrate из веба/PWA** — там отклик = звук + пульс. Это максимум возможного, не баг.
- ВАЖНО: звук «Каталог из другого раздела» живёт в `goCatalog`, остальных пунктов — в их onClick. Не развести по разным местам снова.

### 3.3 Шапка
- При скролле `.header-collapsed`: фон/рамка/блюр сняты полностью («как будто её не было»), заголовок и тема растворяются (ThemeSwitch в `.header-fade`), остаётся плавающая «Назад» 44×44 (h-11 w-11, иконка 20).
- Заголовки — константы `useHeaderTitle`: «Askona Каталог / Askona Остатки / Askona Загрузка фото / Askona Админ», дриллдаун-титулы убраны (путь показывают крошки).
- На десктопе (lg:) шапка обычная, лого + селектор склада на месте.

### 3.4 Поиск
- Кнопки поиска в пилюле НЕТ (4 пункта). Кружок слева (`.search-fab`), при скролле → подвесная стеклянная карточка, фокус в `#global-search`.
- Поле: `bg-secondary/80`, тонкая светлая рамка 1px, focus-рамка брендовая. Вращающийся conic-градиент (источник «мигания») удалён.
- **Популярные запросы:** localStorage `skovo-search-log` = `{q: [timestamp…]}`; запись на commit (Enter/чип/выбор ткани); топ-6 за 7 дней (частота→свежесть), старьё отбрасывается; мерж с серверными popular из `/api/search`.

### 3.5 Ткани
- `Material.colorGroup` (миграция prisma db push). API `?level=fabrics`: приоритет обложки — `Material.swatchUrl` (фото каталога ткани), иначе СВЕЖАЙШЕЕ фото дивана этой ткани по `createdAt`; в ответе `swatchUrl`, `thumb`, `colorGroup`, счётчики.
- Карточка ткани = название + гамма. Карточка варианта = модель + ткань · гамма (variantName и теги Акция/Стандарт/топпер убраны). NEW-бейдж 8px.
- Загрузка фото ткани: админ → раздел «Ткани» → тап по превью → `POST /api/fabric-photo` (sharp → WebP 1200/480, старый файл стирается `purgePhotoFiles`).

### 3.6 Админка
- Разделы: **Товары** (создание товара/вариантов, переименование, мягкое удаление в корзину + оживление), **Ткани** (admin-fabric-manager), **Фотобанк** (мультивыбор, панель выбранных — `sticky bottom-[calc(86px+safe)]`, поднята НАД пилюлей).
- Справочники: занятые (используемые вариантами) защищены — API отвечает 409.
- Загрузка фото товаров: `POST /api/upload` (≤10, EXIF-поворот → 2000px → WebP). ⚠ Маршрут однажды был случайно удалён → загрузка молча ломалась. Не удалять.

### 3.7 Полоса PWA v3 (НЕ ТРОГАТЬ)
- Фикс светлой полосы внизу iPhone: `html { background: var(--edge) }` + `.fx-skirt` + серии nudge в `layout.tsx` и `BootSplash`. Закоммичен тегом `snap/v1.5-protection-v2`. Любая правка низа — только поверх этого.

## 5. Запуск (продакшен — единственный правильный режим)

```bash
cd /home/z/my-project
bun install                # при свежей машине
bun run build              # next build (standalone)
bash scripts/restart.sh    # убить :3000 → node .next/standalone/server.js, ждать HTTP 200
```

## 8. Ловушки (грабли, на которые уже наступали)

1. **Незакоммиченное стирается платформой** → коммитить сразу (§7).
2. **dev-сервер** отдаёт старый CSS → только продакшен-сборка.
3. **Next кэширует public на старте** → restart после добавления файлов.
4. **Процесс `next-server (v16…)` переименован** → `pkill -f server.js` не работает; restart.sh убивает по порту из `ss`.
5. **`html { scroll-behavior: smooth }` ломает программный скролл** → только `behavior:"instant"`.
6. **iPhone:** `navigator.vibrate` отсутствует (звук+пульс — максимум); PWA кэширует манифест; фиксы низа экрана — только через серии nudge (§3.7).
7. **Тесты × живые данные:** владелец удаляет/меняет фото из админки → локаторы «первая карточка с img» падают; писать с фолбэками (уже сделано в s4/s6).
8. **Удаление «неиспользуемых» API/файлов** ломает невидимые связи: удаление `/api/upload` сломало загрузку фото и test-s5.
9. Chrome возвращает computed colors в `oklab`/`rgba` — в тестах только через `alphaOf()`.
