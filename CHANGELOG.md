## v1.5 · Шаг 4 + защита от откатов — 13 сентября

### Инфраструктура защиты (новое)
- **scripts/snapshot.sh** — единая точка фиксации шага: git commit + тег
  `snap/v1.5-<метка>` + зеркалирование в sait_copy_1 + tar-снапшот в
  `download/snapshots/` (включая .git и db) + копии документации в
  `download/logs/` + INDEX.md со сквозной нумерацией.
- **scripts/restore_snapshot.sh** — восстановление из любого снапшота одной
  командой (распаковка → install → prisma → build → перезапуск :3000).
- **Git очищен**: история сжата (была 196МБ — в ней лежал 114МБ tar-архив),
  sait_copy_1 и архивы убраны из отслеживания. Снапшот теперь содержит и
  рабочее дерево, и полную историю git — восстановление возвращает всё.
- **Урок инцидента**: откат песочницы уничтожил .git и бэкап sait_copy_1
  (они жили в откатываемой зоне). Теперь единственный источник истины после
  каждого шага — `download/snapshots/` (постоянная зона).
